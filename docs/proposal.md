# ThanksChain

_Send on-chain thank-you cards with a small SOL tip attached_

## Summary

A simple web app where users send digital 'thank you' cards to friends, with an optional small SOL tip bundled in. Each card is minted as a lightweight NFT so the recipient keeps it as a memory. Built to be the easiest possible way to try sending value and NFTs on Solana.

## Target users

Crypto beginners who want a fun, low-stakes way to try sending tokens and NFTs

## Problem

Sending crypto and minting NFTs still feels technical and intimidating for newcomers.

## Solution

A single-page app that lets anyone mint and send a thank-you card NFT with an attached tip in under a minute.

## MVP features

- Connect wallet (Phantom) with one click
- Pick a card design and write a short message
- Attach an optional SOL tip (fixed small amounts like 0.01/0.05)
- Mint the card as an NFT sent directly to recipient's wallet
- Simple gallery page to view received cards

## Chains

Solana

## Tech

Next.js, Solana Web3.js, Metaplex NFT standard, Phantom Wallet Adapter, Solana Devnet

## Category

Consumer

## Why now

Solana's low fees and fast finality make micro-tipping and NFT gifting practical for everyday casual use, something not viable on expensive chains.

## Roadmap

- Add mainnet support with real SOL amounts
- Let users create custom card designs/templates
- Add social sharing so cards can be posted publicly
